# QuickNotes

QuickNotes is a lightweight web application designed to help users capture and categorize their thoughts instantly.

## Features
- Add notes categorized by Personal, Work, or Study.
- Persistent storage using the browser's localStorage.
- Instant search to filter notes by keywords.
- Validation to prevent empty or excessively long notes.
- Responsive design for mobile and desktop screens.
- Bonus feature: "Clear all" button to delete all notes at once.

## How to Run Locally
1. Clone this repository to your local machine.
2. Open the `quicknotes-app` folder in VS Code.
3. Right-click on `index.html` and select **Open with Live Server**.
